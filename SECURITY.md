# Security and privacy boundary

These packages are local research tools, not authenticated public services. Do not expose their command-line interfaces as web endpoints without separate access controls, input limits, resource isolation and review.

- OBSERVER8 checks authored scenario facts and synthetic authority. Its hashes are not human authentication or an independent guarantee of source truth.
- Operational controls inject adapters and use in-memory records. They do not supply production identity, distributed rate limits, a hard spend budget or trustworthy external receipts.
- The visual renderer invokes local native image and media software. It is not an untrusted-file sandbox. Use approved inputs and reviewed dependency versions.

Never add credentials, live client records, application data, chats or private artwork to an issue or pull request. Report a suspected vulnerability privately to harism@mekreflect.com with a minimized synthetic reproduction. No guaranteed response time or security certification is claimed.

The publication review and pattern scans do not cover every original repository history, third-party dependency, deployed configuration or security threat. Read each package's limits before using it.
